# KarstLab v1.0.0 Release Plan

This plan turns the architecture documents into an execution path optimized for fast delivery with Codex and Claude Code.

## Release Goal

KarstLab v1.0.0 is a cross-platform desktop GIS application that replicates the core ARIS Lidar Prospector V3d workflow:

GeoTIFF DEM input, terrain analysis, fill-subtract doline detection, Top 25 ranking, interactive map display, exports, report generation, project persistence, land profiles, and macOS/Windows distribution.

## Version Gates

| Gate | Target | Outcome |
|---|---|---|
| v0.1.0 | Core setup | Project builds, tests run, packaging spike completed |
| v0.2.0 | Headless analysis | CLI can analyze a DEM and export Top 25 results |
| v0.3.0 | Map and report | Folium map and HTML report generated from analysis results |
| v0.4.0 | Minimal GUI | PySide6 app runs analysis and displays map/results |
| v0.5.0 | ARIS core parity | VRT, contours, hillshade, streams, GPX/KML/GeoJSON |
| v0.6.0 | Project/profile system | `.karstlab`, settings hierarchy, land profiles |
| v0.7.0 | Markers and POI | GPX/KML import, markers, BRGM/Spélébase cache fallback |
| v0.8.0 | i18n and UX | NL/FR/EN, guided workflow, shortcuts, logs |
| v0.9.0 | Release candidate | Installers, real DEM testing, performance checks |
| v1.0.0 | Stable release | Acceptance criteria pass on macOS and Windows |
